# 🗺️ Roadmap

## MadaTours

Version : 1.0

---

## 1. Objectif

Cette roadmap définit les grandes étapes du développement de MadaTours.

Elle permet de :

* suivre l'avancement du projet ;
* définir les priorités ;
* répartir les tâches ;
* planifier les futures évolutions.

Chaque fonctionnalité doit être validée avant de passer à la suivante.

---

## 2. Vision du projet

MadaTours est une plateforme de réservation de circuits touristiques à Madagascar.

Le site doit permettre :

* de découvrir les destinations ;
* de consulter les circuits ;
* de réserver une excursion ;
* de contacter l'agence ;
* de naviguer en plusieurs langues ;
* d'offrir une expérience moderne, rapide et responsive.
